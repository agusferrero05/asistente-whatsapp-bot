# Política de Privacidad – Asistente Personal de WhatsApp

Última actualización: 2026-09-10

Esta aplicación es un asistente personal automatizado de uso exclusivo del
desarrollador, a través de WhatsApp. No está destinada al uso por parte de
otros usuarios ni se ofrece públicamente.

## Datos que procesa

- Mensajes de texto y notas de voz enviados por WhatsApp, para interpretar
  solicitudes (agenda, gastos, notas).
- Acceso a Google Calendar, para crear, consultar y eliminar eventos.
- Acceso a Google Sheets, para registrar gastos y notas.
- Transcripción de audio mediante la API de Groq (Whisper), para convertir
  notas de voz en texto.
- Procesamiento de lenguaje natural mediante la API de Gemini (Google), para
  interpretar las solicitudes.

## Uso de los datos

Los datos procesados se usan únicamente para brindar las funciones del
asistente al usuario propietario. Esta aplicación no comparte datos con
terceros ni los usa con fines publicitarios.
